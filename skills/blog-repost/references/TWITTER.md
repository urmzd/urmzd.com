# Twitter/X Article Formatting

Twitter/X Articles support: **bold**, *italic*, headings, and links. No images, no code blocks, no embeds, no iframes.

## Adaptations

- **Title:** `# Title` — reuse or rephrase the blog title. Punchy.
- **Subtitle (optional):** One line framing the argument below the title.
- **Data links:** Inline only. Lead with the stat so the link has context even unclicked:
  `Productivity grew by **92.4%** while hourly pay grew by just **33.6%** ([EPI Productivity-Pay Tracker](https://www.epi.org/productivity-pay-gap/)).`
- **Section breaks:** `---` between major sections.
- **Length:** 800-1200 words (upper range of canonical body).
- **CTA:** `Read the full version with interactive visuals at https://urmzd.com/blog/{slug}`

## Output Structure

```
# Title

Subtitle if applicable

Body text. Multiple paragraphs separated by blank lines.

---

Section with inline [links](url) for data sources.

---

Read the full version with interactive visuals at https://urmzd.com/blog/{slug}
```
